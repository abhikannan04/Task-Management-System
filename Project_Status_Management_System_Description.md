# Project Status Management System (PSM)

## Project Summary

The Project Status Management System (PSM) is a comprehensive project management platform designed to streamline project tracking, enhance team collaboration, and improve organizational efficiency. This system provides a centralized solution for managing projects, tracking daily progress, and facilitating approval workflows between employees and managers.

The PSM system enables organizations to maintain real-time visibility into project progress, identify potential bottlenecks early, and ensure timely project completion through structured action planning and review processes.

## Project Overview

### Purpose

The Project Status Management System addresses the critical need for organizations to effectively track project progress, manage team contributions, and maintain clear communication between employees and management. Traditional project tracking methods often lack real-time visibility and structured workflows, leading to delays, miscommunication, and project failures.

The PSM system provides a structured approach to project management by:
- Enabling employees to submit daily action plans and progress updates
- Facilitating manager review and approval workflows
- Providing real-time visibility into project status and team contributions
- Supporting data-driven decision making through comprehensive reporting

### Key Objectives

1. **Enhanced Project Visibility**: Provide real-time insights into project progress and team contributions
2. **Streamlined Approval Workflows**: Implement structured review processes for project completions and status updates
3. **Improved Communication**: Facilitate better communication between team members and management
4. **Data-Driven Decision Making**: Enable informed decisions through comprehensive reporting and analytics
5. **Role-Based Access Control**: Ensure appropriate access levels for different user roles within the organization

## Key Functionalities

### 1. Project Management
- **Project Creation**: Admins and managers can create new projects with detailed specifications
- **Project Assignment**: Assign employees to specific projects based on skills and availability
- **Project Tracking**: Monitor project progress through various status indicators
- **Project Lifecycle Management**: Manage projects from planning through completion and archiving

### 2. Action Plan Management
- **Daily Action Plans**: Employees can submit daily action plans with detailed descriptions of their planned work
- **Action Plan Status Tracking**: Track action plans through various statuses (Started, In Progress, Completed, Under Approval, On Hold)
- **Action Plan Review Workflow**: Managers can review and approve/reject employee action plans
- **Action Plan Editing**: Employees can update their action plan status as work progresses

### 3. Approval Workflows
- **Completion Requests**: Employees can request project completion approval from managers
- **Review Process**: Managers can approve or reject completion requests with comments
- **Status Update Requests**: Employees can request status changes that require manager approval
- **Notification System**: Automated notifications for pending approvals and status changes

### 4. Reporting and Analytics
- **Status Reports**: Generate comprehensive reports on project progress and team contributions
- **Export Functionality**: Export data in various formats for external reporting
- **Dashboard Views**: Role-specific dashboards with key metrics and insights
- **Historical Data**: Access to historical project and status data for trend analysis

### 5. User Management
- **Role-Based Access Control**: Three distinct roles (Admin, Manager, Employee) with appropriate permissions
- **Authentication**: Secure JWT-based authentication system
- **User Profiles**: Individual user profiles with relevant information
- **Team Management**: Assign and manage team members across projects

### Manager
- Create and manage projects they own
- Assign employees to projects
- Review and approve employee action plans
- Approve or reject project completion requests
- View team progress and contributions
- Generate reports for their projects

### Employee
- Submit daily action plans for assigned projects
- Update action plan status as work progresses
- Request project completion approval
- View their own project assignments and contributions
- Edit or delete their own action plans
